A document that lives inside the deeply nested `subnet1a` network.

In a correct nav tree this document must appear as a descendant of the
`subnet1` node, which is itself a descendant of the root network — never
as a direct child of the root.

## Details

This file has no cross-network links by design. Its sole purpose is to
give `subnet1a` a visible non-index document so the nav tree contains at
least one non-network leaf node under the nested subnet.
